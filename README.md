# Ortus UI

A front-end documentation site built with **BxSites** (BoxLang static site generator) and the Material theme.

## Overview

Ortus UI is a documentation site for Ortus Solutions products, built using BxSites. It generates a static, searchable website from Markdown source files, using the Material theme for styling and layout.

The project follows the standard BxSites workflow:

**Markdown documentation source** → **BxSites** → **generated static site**

### Key Folders Explained

- **`docs/`** — Source Markdown files. This is the "content source". Each `.md` file becomes a page on the generated site. Frontmatter (YAML at the top) defines `title`, `summary`, and other page metadata.

- **`theme/`** — Custom BxSites Material theme. Contains `.bxm` templates (`layout.bxm`, `nav.bxm`, `page.bxm`, `sidebar.bxm`) and Tailwind CSS config. The theme controls the HTML structure, dark mode, navigation, and responsive layout.

- **`site/`** — **Generated output**. This is what gets deployed to GitHub Pages. Do not edit these files directly — they are regenerated by running `boxlang module:bxsites build`. This folder is gitignored.

- **`draft/`** — Draft content that can be marked with `draft: true` in frontmatter to exclude from the build.

- **`bxsites.yaml`** — Project configuration: name, description, base URL, theme, navigation, and GitHub Pages deployment settings.

## How It Works

```
Markdown documentation source (docs/)
    → BxSites build process
    → Generates static HTML (site/)
        └── Includes: navigation, TOC, CSS (Tailwind), JS assets, search index
```

- BxSites reads Markdown files from `docs/`
- The `theme/` templates define how each page is rendered (layout, navigation, breadcrumbs, table of contents)
- Tailwind CSS provides the styling (configured in `theme/tailwind.config.js`)
- A search index is generated in `site/search-index.json`
- The `site/` folder is the final static site ready for deployment

## Requirements

- **BoxLang** v1.17.0+ (runtime)
- **BxSites** module v1.0.0-snapshot
- Node.js (for Tailwind CSS build, optional — can use `boxlang module:bxsites` which bundles its own dependencies)
- Tailwind CSS (dev dependency, managed via `theme/package.json`)

## Local Development

Start the local development server with live reload:

```bash
boxlang module:bxsites serve --projectRoot=/path/to/ortus-ui --port=8080
```

Available BxSites verbs:

| Verb | Description |
|------|-------------|
| `build` | Render `docs/**.md` into `site/` |
| `serve` | Build and serve locally with live reload |
| `clean` | Remove `site/` and build cache |
| `check` | CI-grade content check on built site |
| `lint` | Pre-build content checks |

## Build

Generate the static site:

```bash
boxlang module:bxsites build --projectRoot=/path/to/ortus-ui
```

This reads all Markdown from `docs/`, processes them through the theme templates, and outputs the static site to `site/`.

## Deployment

The project is configured for GitHub Pages deployment (see `bxsites.yaml`). To deploy:

```bash
use: bxSites deploy --target=github-pages --branch=gh-pages --remote=origin
```

Or use the GitHub Actions workflow that builds and deploys to `gh-pages` branch automatically.

The deployment configuration in `bxsites.yaml`:

```yaml
deployments:
  github:
    provider: github-pages
    repository: jlainezsv/ortus-ui
    branch: gh-pages
```
